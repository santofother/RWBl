## What exists now
- `MatchMode`: rounds repeat until someone wins. `rounds` 0 = unlimited (default); `--rounds=N` is a test cap.
  Win = finish 1st AND total **before that race** ≥ `win_score` (1000). `[Game] WIN slot N score S` (S = total after
  the race). `[Game] MATCH POINT slot N` the first time a slot is ≥ win_score at the start of a round.
- Interpretation: the card's example (900 → win → 1100, match goes on) means the check uses the pre-race totals
  (`_pre_race_totals`, snapshot on entering RACE). So reaching 1000 only gives match point; the *next* 1st wins.
- Grand Circus removed (`is_grand_circus`, `grand_circus_extra_laps`, extra laps) — nothing else used it.
- `ScoreTable` ×30: finish 150/100/70/40/0, trap 30 (cap 90), kill 60, self −30, lap 25, clean 25, mercy 25,
  fewest deaths 50; ranges widened. HUD: `Round %d · Phase` + `MATCH POINT: names` in the phase label.

## Public API
- `MatchMode.winner_slot(finish_order, totals, win_score) -> int` (static, -1 = none), `match_point_slots() -> Array[int]`.
- New standalone CLI `--race-time=SEC` (race length only; `--phase-time` still sets all). Not yet in AGENTS.md Commands.

## How to test
- `tools/tests/match_test.sh` → `MATCH TEST PASSED` (adds all-at-1000 win, slot-0-only-at-1000, no-cap round 7, and
  `match/tests/match_rules_test.tscn` unit). `score_test.gd` expectations updated to the new table.
- Manual: F6 `game/match/match.tscn` with `-- --test-totals=0:1000`: win a race → results screen; with `0:990`
  win one → you're past 1000, HUD shows MATCH POINT, match goes on; win again → results.
