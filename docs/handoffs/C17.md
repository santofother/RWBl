## What exists now
- `items/defs/demolish.tres`: uncommon WILDCARD, cost 1, **no scene** (= targeting card). Draft deals it like any card; free build hands include it.
- `build/build_phase.gd`: `request_demolish(uid)` → host `validate_demolish` (order: phase, uid, card, budget; reuses `PlaceResult` WRONG_PHASE / UNKNOWN_ITEM / NOT_IN_HAND / OVER_BUDGET) → `_rpc_demolish` on every peer: card spent (hand + cost), `_items.erase`, `queue_free`, `GameEvents.item_removed(uid)` once, log `[Build] DEMOLISH <uid> by <slot>`. Answer = `place_result(code, &"demolish")`. Items from this same phase can be demolished. Placing a targeting card via `validate()` → UNKNOWN_ITEM.
- Bots place first, demolish last: target = not their own item, nearest the centre line (the leader's racing line); none → skip (`[Build] bot N has no target`). A held Demolish doesn't block "finished" while the track is empty.
- `build/build_ui.gd`: holding Demolish there's no ghost, a red box over the item under the mouse, LMB removes it, empty ground = nothing happens. Toast "Demolish: removed it".
- `# TODO(T1):` in `validate_demolish` for track pieces.

## Public API
- `BuildPhase.request_demolish(uid)`, `demolish_for_slot(slot, uid) -> int` (host), `validate_demolish(slot, uid) -> int`, `demolish_card(slot) -> StringName`, `item_at(pos) -> uid|-1`, static `is_targeting(def)`.
- Test hooks: `--test-place` entry `demolish@uid[,slot]`; `--test-race-demolish=uid,slot` (host, at RACE start → `[TEST] RACE DEMOLISH uid -> CODE`). With `--test-place` every peer prints `[TEST] ITEM_REMOVED uid`.

## How to test
- Headless: `tools/run_tests.sh build` → `BUILD TEST PASSED` (solo: demolish OK / gone uid / unknown uid / no card / in RACE; mud fits where the oil was. Lobby: client demolishes the host's oil over RPC, removed once on both peers). `tools/run_tests.sh items` adds "removed oil gives the road back".
- Manual: in Godot, menu **Debug → Customize Run Instances…**, tick **Enable Main Run Args**, type `-- --free-build`, OK. FileSystem → `game/match/match.tscn` → **F6**. In Build, click **Oil Slick**, left-click the road to place it. Click **Demolish (1)**, hover the oil (red box, "Click to remove Oil Slick"), left-click → it vanishes, toast "Demolish: removed it". Clicking empty road does nothing and keeps the card. Afterwards untick Enable Main Run Args.
