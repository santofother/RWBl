## What exists now
- `RaceController`: one run start → finish. Position = `Track.progress_at` (shortcuts count). Finish = crossing `finish_progress()` in one normal tick, inside the road (±1 m), moving forward. No checkpoints/laps; `clean_lap(slot, 1)` once at the finish for a run without collisions (`[Race] CLEAN slot`). New `to_go(slot)`; `lap_of()` always 1.
- Bots: stop in the run-off after the line; `[Bot] FINISH slot n` replaces `[Bot] LAP`.
- Scoring: no per-lap points (`lap_completed` earns nothing); clean run +25 once. `ScoreTable.lap` kept but unused.
- HUD: lap counter shows `N m TO GO` / `FINISHED`. `--laps` is ignored with a warning (standalone match); the lobby still passes it but nothing reads it.

## How to test
- `tools/run_tests.sh race`, `bot_race`, `score` (all updated for no laps). `bot_soak_test` now plays 6 full rounds (bots draft and place pieces, the course grows) and checks every bot finishes.
- Manual (user): Godot → **Debug → Customize Run Instances…** → tick **Enable Main Run Args**, type `-- --bots=3` (leave out `--free-build`, so you get the real draft). FileSystem → `game/match/match.tscn` → **F6**.
  1. Draft: 3 cards appear; click one to keep it.
  2. Build: click your card on the left. If it is a track piece, yellow discs show every joint; move the mouse, the nearest disc turns white and a green road shows where the piece goes plus the whole new course. **R** flips a hairpin/chicane. Left-click → the course grows. For an item, click on the road.
  3. Race: drive from the start line to the gate (top-left shows metres to go). 4. Score: bars climb to the 1000 line.
  To try pieces every round, use `-- --free-build --bots=3` instead (every card in your hand).

## Design question
- The course only grows. Bots need ~40 s for 600 m and ~95 s for 1200 m, so with the default 90 s race limit
  (MatchTuning.race_time) races start timing out around round 4–5 when several players draft pieces. Options:
