# C19 — Track pieces framework + hairpin and chicane
Agent: Claude Opus 5.5 · effort high · branch `c19-track-pieces`
Result: DONE (ghost/visuals checked headless only; the manual test below covers the look and feel)

## What exists now
- `track/pieces/track_piece.gd` (`TrackPiece`, shape built in code from `_straight`/`_arc`, starts at 0 heading -Z, ends at (0,0,-chord)), `hairpin.gd/.tscn` (90° out, 30 m leg, r 11 U, back; chord 42 m, +84 m road, rare), `chicane.gd/.tscn` (4 arcs r 20 × 40°; chord 51.4 m, uncommon). Defs `items/defs/piece_hairpin.tres`, `piece_chicane.tres` (cost 1, category PIECE). Shape knobs are `@export`s on the scenes.
- `Track`: pieces are stored in original-curve progress; the centre line is recomposed (1 m Hermite points) from base + pieces, then road/walls/bounds rebuilt. Removing a piece restores the old road exactly. Pieces only go on straight stretches of the original road, ≥ 40 m from the line, 4 m apart, and the new road must stay `track_width + 2·wall` from every non-neighbouring part of the loop. Check ≈ 1 ms, splice ≈ 6 ms.
- `BuildPhase`: `request_piece` → host `validate_piece` → `_rpc_place_piece` (every peer splices in order) → host relocates items on the section (`[Build] PIECE moved|displaced <uid>`). Demolish works on pieces (C17's `TODO(T1)` resolved). Free-build bots place pieces too. Path grid rebuilt after `track_changed`.
- `BuildUI`: holding a piece the ghost is a road ribbon centred on the mouse, snapped along the centre line; R (or Q/E) flips; reason text from `Track.splice_text`. Demolish highlights a piece's whole road.

## Public API (for C20)
- `Track.splice_piece(id, start, flip=false, uid=-1) -> bool`, `check_splice(id, start, flip) -> Track.Splice.*` (OK UNKNOWN START_ZONE NOT_STRAIGHT OVERLAP SELF_INTERSECT), `apply_splice(uid, id, base_start, flip) -> uid` (no checks), `remove_piece(uid) -> bool`, `has_piece`, `piece_at(pos) -> uid|-1`, `pieces() -> [{uid id start end flip base_start}]`, `to_base_progress(p)`, `piece_world_points(id, start, flip)`, static `splice_text(code)`, `points_to_curve(pts, tans)`.
- `TrackPiece.build_points() -> [points, tangents]` (override `_shape()`), `chord()`, `flippable`. Points keep their y, so C20 hills only need a `_climb()`-style builder; `_local_t()` flattens the heading.
- `BuildPhase.request_piece(id, start, flip)`, `place_piece_for_slot(slot, id, start, flip) -> int`, `validate_piece(...) -> int`, `last_splice_code`. Signal `GameEvents.track_changed()` (every peer, after each splice/removal).

## How to test
- Headless: `tools/run_tests.sh track_piece` → `TRACK PIECE TEST PASSED` (unit checks; illegal splices; mud moved/displaced; 3 bots finish 1 lap on hairpin + chicane in ~50 s; host + client identical track after splice, RPC chicane and RPC demolish).
- Manual: Godot → **Debug → Customize Run Instances…** → tick **Enable Main Run Args**, type `-- --free-build --bots=3`, OK. FileSystem → `game/match/match.tscn` → **F6**. In Build click **Hairpin (1)**, move the mouse along the start straight: a green road outline follows; near the start line or on a corner it turns red with the reason. Press **R** to flip it to the other side. Left-click → the road reshapes. Click **Done placing** and race it. Afterwards untick Enable Main Run Args.
