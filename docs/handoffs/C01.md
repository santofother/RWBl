## How to test
- Headless: `tools/run_tests.sh` → `ALL TESTS PASSED` (net_test prints `NET TEST PASSED`). Running Godot needs the sandbox off.
- Manual: 1) Open Godot, **Import** → pick `CustomChariot/rwbl/project.godot` → **Import & Edit**.
  2) Top menu **Debug → Customize Run Instances…** → tick **Enable Multiple Instances**, set count to **2** → OK.
  3) Press **F5**. Two windows open. 4) Window 1: click **Host (LAN)**. 5) Window 2: leave `127.0.0.1`, click **Join IP**.
  6) Click into either window and press WASD: its cube moves in both windows. F3 shows ping/peers.
