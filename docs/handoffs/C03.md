## What exists now

- UDP host advertisements every 1 s; stale hosts expire. Admission rejects mid-match joins before game RPCs.

## Public API (what other cards can use)
- `Lobby.start_match() -> bool`: host-only, requires every human ready; builds PlayerInfo/rules, calls setup() on all peers, then start() on host. GameMode.finished drives results/return.
- `LanDiscovery.listen(port)`, `advertise(discovery_port, name, game_port, players)`, `stop()`; `hosts_changed(Array[Dictionary])` emits local host entries. No game imports.
- CLI: `--auto-ready`, `--lobby-autostart=N` (host auto-readies, starts once), `--discover`, `--discovery-port=N` (default 24691), `--no-fill-bots`; `--rounds`, `--laps`, `--phase-time`, `--quit-after` work in lobby.
