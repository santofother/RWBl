## What exists now
- `match/match_tuning.gd` + `default_tuning.tres` (F2 → "Match"): `rounds 6, laps 1, win_score 30,
  grand_circus_extra_laps 1`, phase seconds `draft 10 / build 25 / race 90 / score 10`, `cards_per_hand 3`,
  `weight_common 6 / uncommon 3 / rare 1`, `catchup_from_round 2`, `last_place_rares 1`, `leader_commons_only 1`.
  `rules` = tuning → `DEFAULT_RULES` (`start_phase`, `free_build: false`) → lobby/CLI rules (rules win).
- `MatchMode`: any phase ends early on `phase_end_requested` (applied next physics tick, never nested). After SCORE:
  a total ≥ `win_score` (`[Game] WIN slot s score n`) or last round → results. Final round = Grand Circus (`laps` +1 on
  every peer, `[Game] GRAND CIRCUS`); **not in a 1-round match** (keeps the race tests' lap counts). Client leaves →
  `[Game] DROPOUT slot s -> bot` on every peer + `roster_changed` (Bots/ChariotSync already react).
- `Draft`: weighted deal, distinct cards per hand, catch-up by `m.totals()` (ties: everyone on the lowest/highest
  total; nobody when all tied). Bots keep their rarest card at once; dropped players' slots pick when they become bots.

## Public API (for C11 / C14)
- `MatchMode.totals()` (Scoring totals + `--test-totals`), `tuning`, `is_grand_circus()`.
- `Draft.cards_of(slot)`, `hand_of(slot)`, `has_picked(slot)`, `submit_pick([i])` (exactly `Draft.KEEP` = 1),
  signals `hand_dealt(slot, cards)` (owner's peer; host for bots), `hands_final(hands)` (all, before BUILD),
  `picked(slot, id)` (host). Timeout keeps card 0 (`[Draft] KEEP s id timeout`).
- CLI: `--test-totals=slot:points,...`, `--free-build` (no deal, Draft ends at once, Build = every item; also
  implied by C08's `--test-place`). Host-only flag: clients' build UI still reads their own rules.
