## What exists now
- `track.tscn` has a `Path3D` "Path" (the centre line, editable in the editor; last point = first). Road, walls
  (layer WALL, trimesh) and ground are generated from it in `track.gd`. `game/track/tools/gen_track.gd` generated the
  curve once (straights + arcs); you never need it again. All `Track` API kept.
- Pit mode (`pit = true` in track.tscn): the road is a floating slab over a bottomless pit, no walls, no ground;
  falling past y -30 kills (`fall`). Until C12, the race respawns a dead chariot after 2 s at its last checkpoint
  (`[Race] RESPAWN`, remove `_respawn_dead()` then). `Track.new()` (tests) keeps flat ground + walls.
- `RaceController`: RACE → grid, `frozen`, 3 s countdown, `[Race] GO`, ordered checkpoints, laps = `rules.laps`,
  `lap_completed` / `clean_lap` / `chariot_finished` / `race_over`, `phase_end_requested` 3 s later. Lap/place/finish
  state RPC'd to clients at 4 Hz. Extra API: `finish_time_of`, `countdown_left`, `is_racing`, `notify_teleport`.
- `RaceCamera`: smoothed chase, heading slerp, speed FOV 68→88°.
