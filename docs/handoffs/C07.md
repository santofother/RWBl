## What exists now
- `net/chariot_sync.gd`: input queue per slot (3 inputs/packet, old `seq` ignored, queue capped at 4 + slow drain),
  snapshot buffer keyed by host time, remote render at `interp_delay` (≥ 100 ms, grows with snapshot age + jitter),
  lerp/slerp/lerp_angle, ≤ 150 ms extrapolation, no streak on teleports (> 5 m between snapshots).
- Own chariot prediction: client steps locally, stores predicted state per seq; each snapshot carries the host's
  last stepped seq for every slot; client removes 35 % of the error (pos, rot, vel, cart, stamina) per snapshot from the
  live state and newer history, snaps if > 3 m. Wheels/flags (dead, frozen, stun) always come from the host.
- Lag sim `--lag-ms`, `--loss`; `--no-predict`; F3 net label (RTT, interp delay, kB/s). `roster_changed` resets owners.
- `net/tests/net_test_driver.gd` (only with `--net-autotest`), `tools/tests/chariot_net_test.sh`.
## Packet format
- Snapshot (host → all, unreliable_ordered, 30 Hz): f64 host_time, then per chariot u8 slot, u32 ack_seq, 15 × f32
  `ChariotSnapshot` (65 B). Input (client → host, 60 Hz): up to 3 × 10-byte `ChariotInput`, newest first.
- Bandwidth payload at 5 players: snapshot 333 B × 30 = 9.8 kB/s down per client (host up ≈ 39 kB/s for 4 clients);
  input 30 B × 60 = 1.8 kB/s up per client. Add ≈ 1.5 kB/s UDP/ENet headers per direction.
## Public API
- Unchanged + `sample_remote(slot, host_time)`, `render_time()`, vars `prediction lag_ms loss_pct rtt_ms interp_delay
  kbps_in kbps_out`. Tunables are consts at the top of `chariot_sync.gd` (`# TUNE`).
## How to test
- Headless: `tools/tests/chariot_net_test.sh` → `CHARIOT NET TEST PASSED`
  (100 ms each way: remote error 0.06 m, own response 0 ticks, final 0.03 m; also passes with `NET_EXTRA=--loss=10`).
- Manual: 1) Export macOS (`docs/STEAM_EXPORT_AND_TESTING.md`). 2) Terminal 1: `build/macos/RWBL.command -- --host
  --lag-ms=100`; Terminal 2: `build/macos/RWBL.command -- --join=127.0.0.1 --lag-ms=100`. 3) Both click **Ready**, host **Start**,
  wait out draft/build, drive (W/A/S/D). Press **F3**: top-right shows RTT. Does your chariot feel instant? Do the
  others move smoothly? Try `--loss=10` too. Then two machines on LAN without the flags.
